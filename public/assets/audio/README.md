# Voz opcional

Carga desde la interfaz un WAV propio o con licencia con un “wow” de voz femenina adulta, o coloca ese archivo aquí con el nombre `wow.wav`. Se usarán los primeros 1,5 segundos en cada evolución. No se incluye una voz generada. Sin este archivo, la exportación incluye los efectos originales de monedas y caja registradora.

Este archivo también conserva el directorio de audio al clonar o descargar el repositorio. El WAV cargado se ignora en Git.
